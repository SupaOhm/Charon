# Showcase script

This is a proposed demonstration excerpt, not a completed endless run. No duration has been measured. The route below has not been verified against a v0.3 engine. Rehearse it with the integrated build and use its current previews.

## Introduction

[Start a new v0.3 run. Show the starting shore and status display.]

“You are Charon's apprentice, a carrier and guide. Any destination accepts any passenger. The responsibility is to deliver those you take aboard before returning. This is a fictional adaptation, and this demonstration shows an excerpt of an endless run.”

## Passenger choice

[Read the actual soul cards. In the specified opening, select Mother, Child and Merchant. Confirm their cohort IDs and four occupied seats.]

“Mother and Child are linked. Taking them together fills three seats. Merchant uses the last seat. Their wishes suggest different destinations, so the boat can make more than one delivery stop. Souls left here keep waiting. Their anger changes only when the cycle returns.”

## Route choice and delivery

[Compare the available route previews. Select Elysium only after inspecting fog damage, hull damage and warnings. Confirm departure if proceeding with the excerpt.]

“A crossing is one edge. The preview shows its fog damage, with hull damage shown separately. Reaching exactly zero light survives. A failed crossing gives no arrival rewards.”

[If arrival succeeds, select Mother and Child together and confirm delivery. Leave Merchant aboard. If an event appears, read its now-revealed text. Do not open the spoiler reference unless demonstrating that feature deliberately.]

“These two leave in the same action. Their wishes match this destination. Delivering them together earns one Joined Memory from each. Merchant remains aboard for another stop. A different destination would still fulfill the delivery promise.”

[Show the drawn memories. Compare an available second destination, such as Tartarus, using the current preview. Demonstrate a free memory if useful, then deliver Merchant at the chosen destination after a successful crossing. Resolve any revealed event. Do not describe a route as safe without checking the live state.]

## Return explanation

[Show the return preview and forecast before confirming. If return or arrival fails, show the recorded cause and end the excerpt there. Do not narrate steps the game did not complete.]

“On a successful return, unprotected waiting souls gain normal anger, and separated waiting partners gain additional anger. Souls reaching at least three anger become wraiths and add reprimands. Passengers brought back undelivered also add reprimands. Every third completed cycle settles a two-obol quota. Three reprimands end the run. These checks happen before recovery or another action.”

[If the cycle and its checks are survived, show the next cycle.]

“The lantern recovers one light and the shore refills toward five. New arrivals are different people and get no anger for the cycle just finished. This is a checkpoint, not a victory. The run continues.”
